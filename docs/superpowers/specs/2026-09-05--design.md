# `yeddes.com` — Portfolio Skeleton (Design Spec)

**Status:** Draft v1 — awaiting user review
**Date:** 2026-09-05
**Owner:** Ayman Yeddes
**Scope:** UI skeleton for `yeddes.com` — deployable today, content fillable later

---

## 1. Goal

Ship a portfolio skeleton for `yeddes.com` that:

- Positions the owner as both a **full-stack developer** and a **project manager**.
- Is **deployable on day one** with placeholder content, so the domain can go live immediately.
- Is **maintainable without code**: the only file the owner needs to edit long-term is `src/content/data.ts`.
- Feels **modern, professional, and quietly technical** — recruiter-safe, dev-respected.
- Uses a **blue + cyan-mint** palette with a **dark default + light toggle** theme.

## 2. Non-Goals (v1)

- No blog, no CMS, no database, no auth, no contact-form backend.
- No multi-language switching (English only in v1; i18n is easy to add later).
- No analytics integration (can be added as a single script in `layout.tsx`).
- No light-mode-only or dark-mode-only mode (toggle ships with both designed).
- No 3D / Spline / heavy WebGL assets.

## 3. Target Audience

- **Primary:** technical recruiters and hiring managers scanning for a 30-second read.
- **Secondary:** prospective clients evaluating a freelance dev+PM.
- **Tertiary:** peer developers checking the stack and code quality.

Every design decision optimizes for "looks credible in a screenshot AND navigable in 30 seconds."

## 4. Tech Stack (locked)

| Layer | Choice | Notes |
|---|---|---|
| Framework | **Next.js (latest stable, App Router)** | Pinned to whatever is current in Sept 2026 (v15 or v16). Static-first; can add routes later without rewrite. |
| Language | **TypeScript** (`strict: true`) | Type-safe content. |
| Styling | **Tailwind CSS (latest stable v4+)** | One design system, two themes via CSS variables. |
| Animations | **Motion (formerly Framer Motion)** | The `motion` package on npm; React entry is `motion/react`. Scroll reveals, hover lifts, theme transitions. |
| Icons | **lucide-react** | Tree-shakeable, consistent. |
| Fonts | **Inter** (body) + **JetBrains Mono** (code) via `next/font` | Self-hosted, zero CLS. |
| Theming | **next-themes** | No flash on load. |
| Content | **`src/content/data.ts`** (typed) | No DB, no CMS, no markdown engine. |
| Package manager | **pnpm** | Lockfile is `pnpm-lock.yaml`. |
| Repo | **GitHub** (public recommended) | Created by the owner. |
| Deploy | **Vercel** | Free tier, auto-deploy on push, custom domain in 2 clicks. |

### 5.2 Gradient (brand signature)

`linear-gradient(135deg, var(--brand) 0%, var(--accent) 100%)` — used on:
- Logo mark
- Primary CTA button background
- Section dividers
- Project card hover glow

### 5.3 Typography

- **Display** (h1, h2): Inter, `font-weight: 700`, tight tracking (`-0.02em`).
- **Body**: Inter, `font-weight: 400`, line-height `1.6`.
- **Code/accents** (badges, role tags): JetBrains Mono, `font-weight: 500`.
- **Type scale:** `text-sm` (14px) → `text-base` (16px) → `text-lg` (18px) → `text-xl` (20px) → `text-2xl` (24px) → `text-4xl` (36px) → `text-6xl` (60px on mobile, 72px on desktop).

### 5.4 Spacing & layout

- **Container max-width:** `1200px` (Tailwind `max-w-6xl`).
- **Section vertical padding:** `py-20 md:py-28` (generous, scroll-friendly).
- **Grid gaps:** `gap-6` for cards, `gap-4` for inline lists.
- **Border radius:** `rounded-xl` for cards, `rounded-full` for tags/pills, `rounded-md` for buttons.

## 7. Section Specs (in detail)

### 7.1 Nav (sticky)

- Logo on the left: gradient "Y" mark + "yeddes.com" text (linked to `#top`).
- Center/right: anchor links `About · Stack · Projects · Experience · Contact`.
- Far right: `ThemeToggle` (sun/moon icon) + small `Get in touch` button (anchor to `#contact`).
- Becomes solid + adds `backdrop-blur-md` after scrolling past the hero (>80px).
- Mobile: hamburger that opens a full-screen menu.

### 7.2 Hero

- **Headline:** "Hi, I'm **\[Name\]**." (h1, 60–72px).
- **Roles line:** gradient text "Full-Stack Developer · Project Manager" (h2, with bullet separator).
- **Tagline:** one sentence, max 14 words, `text-lg text-fg-muted`.
- **CTAs:** primary "View projects" (scrolls to `#projects`), ghost "Get in touch" (scrolls to `#contact`).
- **Status pill:** `● Available for work` (emerald dot, small uppercase text). Can be flipped via a single `profile.availableForWork` boolean in `data.ts`.
- **Visual element:** subtle animated gradient orb or grid pattern behind the text (CSS only, no asset).

### 7.3 About

- Two-column on desktop (text left, avatar right), stacked on mobile.
- Avatar: 240×240 rounded square with gradient border; placeholder = initials in monogram style (SVG, no external image required to deploy).
- Bio paragraph (3–5 sentences).
- **Quick facts grid** (2×2 or 4×1 on mobile): `Years of experience`, `Location`, `Languages`, `Focus areas`. Each fact is a small label + bold value.

### 7.4 Tech Stack

- Section heading: "What I work with."
- 4 columns on desktop, 2 on tablet, 1 on mobile.
- Each column = category: `Frontend`, `Backend`, `Infra & DevOps`, `PM Tools`.
- Each item = icon (lucide) + label. Hover: subtle lift + brand color tint.
- Item data is driven entirely by `data.ts` → swap tools by editing one file.

### 7.5 Featured Projects

- 2-column grid on desktop, 1 on mobile.
- Each card:
  - Title (h3).
  - Role tag (`Lead Dev` / `Tech PM` / `Solo` / `Open Source`) — pill with brand color.
  - Outcome line (1 sentence, bold).
  - Description (1–2 sentences).
  - Tech tags (small pills, monospace).
  - Links row: `Live ↗` · `Repo ↗` · `Case study ↗` (only show the ones that exist).
- Hover: card lifts (`-translate-y-1`) + gradient glow border.
- 3 placeholder projects ship in the skeleton.

### 7.6 Experience

- Vertical timeline with a glowing brand-color line on the left.
- Each entry:
  - Dot marker on the line (brand color, glow on hover).
  - `Role · Company` heading.
  - Date range (`Jan 2023 — Present` or `Jan 2023 — Dec 2024`).
  - 1–2 bullet outcomes (start with a verb, max 14 words each).
- Most recent entry first.
- 3 placeholder entries ship in the skeleton.

### 7.7 Contact

- Heading: "Let's build something."
- Subline: "Open to freelance, contract, and full-time roles."
- **Email button** (primary, gradient) — `mailto:hello@yeddes.com`.
- **Social icons row** (GitHub, LinkedIn, X/Twitter, optional: Instagram, Dribbble) — icon-only buttons, square, hover brand color.
- No form (v1). Form can be added later as `/contact` page or third-party widget (Formspree, Resend).

### 7.8 Footer

- Three columns: brand+tagline (left), nav links (center), socials (right). Stacked on mobile.
- Bottom row: `© 2026 Ayman Yeddes · Built with Next.js · ↑ Back to top`.

## 8. Animations (subtle, never gimmicky)

| Trigger | Animation | Library |
|---|---|---|
| Section enters viewport | Fade + `translateY(8px) → 0` | Framer Motion `whileInView` |
| Hero gradient orb | Slow CSS `conic-gradient` rotation, 30s loop | CSS |
| Nav scrolls past hero | Background opacity 0 → 1, blur 0 → 12px | Framer Motion |
| Project card hover | `translateY(-4px)`, gradient border opacity 0 → 1 | Tailwind + Framer |
| Theme toggle | Crossfade sun ↔ moon, color transition 200ms | Framer |
| Anchor link click | `scroll-behavior: smooth` on `<html>` | CSS |

No `prefers-reduced-motion` violations — all animations respect the user's OS setting.

## 11. SEO & Metadata

- `<title>`: `Ayman Yeddes — Full-Stack Developer & Project Manager`.
- `<meta name="description">`: tagline + location.
- **Open Graph image**: auto-generated by `app/opengraph-image.tsx` using a server-rendered React component (Next.js feature, no external image needed).
- **Twitter card**: `summary_large_image`.
- **JSON-LD `Person` schema** in `layout.tsx` with name, jobTitle, url, sameAs (socials).
- `app/sitemap.ts` and `app/robots.ts` for crawlers.
- `favicon.svg` (modern, brand-colored "Y" mark).

## 12. Accessibility

- All interactive elements have visible focus rings (brand color, 2px).
- Color contrast: dark mode text passes AA on the deep navy background; light mode passes AAA.
- `prefers-reduced-motion` respected globally via a single `globals.css` media query.
- Semantic HTML: `<header>`, `<main>`, `<section>`, `<nav>`, `<footer>`, proper heading hierarchy.
- Mobile menu traps focus when open; Escape closes it.
- All icons have `aria-hidden="true"` if decorative, or descriptive `aria-label` if functional.

## 13. Performance Targets

- **Lighthouse mobile**: ≥ 95 on Performance, Accessibility, Best Practices, SEO.
- **Largest Contentful Paint**: < 1.8s on simulated 4G.
- **Cumulative Layout Shift**: < 0.05.
- **First Load JS**: < 200 KB (gzipped). No heavy libraries beyond Framer Motion (~30 KB gz) and lucide-react (tree-shaken).
- Static export where possible (no runtime data fetching).

## 14. Browser Support

- Last 2 versions of Chrome, Firefox, Safari, Edge.
- iOS Safari 16+, Android Chrome 120+.
- Graceful degradation: animations disabled, `backdrop-blur` falls back to a solid background, glassmorphism still readable.

## 15. Deployment

### 15.1 Steps (after skeleton is built)

1. **Owner creates a public GitHub repo** (e.g. `yeddes.com` or `yeddes-portfolio`).
2. **Owner pushes the skeleton** (initial commit, or unzips and `git init` + `git remote add`).
3. **Owner imports the repo into Vercel** (vercel.com/new → "Import Git Repository").
4. **Vercel auto-detects Next.js** → clicks "Deploy" → live at `<project>.vercel.app` in ~60 seconds.
5. **Owner adds `yeddes.com`** in Vercel project settings → Domains.
6. **Owner copies the 2 DNS records** (A and CNAME) to their domain registrar.
7. **Vercel provisions SSL** automatically (5–10 min). Site is live at `https://yeddes.com`.

### 15.2 What the README will say

- Prerequisites: Node 20+, pnpm 9+.
- `pnpm install` → `pnpm dev` → open `localhost:3000`.
- "Edit `src/content/data.ts` to update your bio, projects, experience, and socials. Push to `main` → Vercel auto-redeploys."
- Troubleshooting (font flash, theme flash, build errors).

## 16. Acceptance Criteria (definition of done)

The skeleton is **done** when:

- [ ] `pnpm install && pnpm dev` boots a clean local server with no warnings.
- [ ] `pnpm build` succeeds with zero TypeScript errors and zero ESLint errors.
- [ ] All 6 sections render with the placeholder data from `data.ts`.
- [ ] Dark/light toggle works without a flash on initial load.
- [ ] Nav anchor links scroll smoothly to the correct sections.
- [ ] Mobile menu opens, closes, and traps focus.
- [ ] All links (email, socials, project links) are present in the HTML (even if pointing to `#` in the placeholder).
- [ ] Open Graph image renders correctly when sharing on LinkedIn/Twitter.
- [ ] Lighthouse mobile score ≥ 95 on all 4 categories.
- [ ] `prefers-reduced-motion` disables scroll animations.
- [ ] README explains how to edit content and deploy.

## 17. Out-of-scope (for a future version)

- Blog with markdown-based posts and `/blog/[slug]` routes.
- i18n (English / French / Arabic) with `next-intl`.
- Contact form backed by Resend or Formspree.
- Plausible / Umami analytics.
- View-transition API animations between sections.
- OG image generation customized per-project.
- CMS-driven content (Sanity, Payload, Notion-as-CMS).

## 18. Risks & Mitigations

| Risk | Mitigation |
|---|---|
| Tailwind v4 is still new — some plugins lag | v4 stable is the lock-in; we use only the core features, no plugins. |
| Framer Motion bundle size | Use only on the 6 section reveals + nav; tree-shakes well. |
| Pinned version drift | Spec is written for "latest stable" — actual install will resolve to whatever Next.js / Tailwind / Motion versions are current on install day. |
| Font flash on first paint | `next/font` with `display: 'swap'` and preloaded subsets. |
| Theme flash on first paint | `next-themes` injects an inline script before hydration. |
| Owner breaks content with bad data | Strict types in `types.ts` make most typos fail at build time. |
